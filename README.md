# Data Analysis on Consumer Behaviour & E-Commerce

## Overview
An academic data analysis project exploring consumer purchasing patterns in e-commerce. The project uses exploratory data analysis, visualization, and statistical techniques to study customer demographics, purchase amounts, product categories, review ratings, and shopping preferences.

## Objectives
- Identify trends in consumer purchasing behaviour.
- Analyze spending patterns across age groups and locations.
- Examine product categories, customer ratings, shipping types, and payment preferences.
- Investigate relationships between selected variables using correlation and hypothesis testing.
- Derive insights that can support customer satisfaction and business decision-making.

## Tech Stack
- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, SciPy

## Analysis Performed
- Data inspection and preprocessing
- Descriptive statistics and exploratory data analysis (EDA)
- Purchase amount distribution analysis
- Product category and customer demographic analysis
- Data visualization using histograms, box plots, bar charts, pie charts, line charts, and heatmaps
- Pearson correlation analysis
- Hypothesis testing at a 0.05 significance level
- 95% confidence interval estimation

## Setup and Execution

### Prerequisites
- Python
- Visual Studio Code
- Python and Jupyter extensions for VS Code

### Steps
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Place the dataset in the project folder.
4. Open `idsproject.ipynb` in VS Code.
5. Select a Python kernel.
6. Run the notebook cells sequentially from top to bottom.

**Note:** The dataset filename and path must match those used in the notebook.

## Expected Outputs
The analysis produces statistical summaries and visualizations illustrating purchasing patterns, spending distributions, product category trends, customer ratings, and relationships between selected variables.

## Conclusion
The project applies data analysis and statistical inference to e-commerce consumer data to explore purchasing behaviour and identify insights relevant to customer preferences, marketing, and business operations.
